OPay-inspired website practice project

Files:
- index.html: website structure
- style.css: styling and responsive layout
- script.js: mobile navigation menu
- assets/opay-mark.svg: recreated practice favicon/mark

How to open:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html and use Live Server, or double-click index.html to open it in a browser.

Note: This is an unofficial educational front-end recreation inspired by OPay. It is not the official OPay website or app. It does not process payments, create accounts, or collect personal information. The logo mark is a simplified recreation. Links to learn more lead to the official website.
